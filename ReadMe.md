# Settings Search

Adds a search bar to the options menu to quickly find any mod's settings

Easily find any mod's settings page quickly without scrolling and looking for it

## Features

- A search box in the Options menu, right above the list of mod settings pages to easily find any mod's settings page through the growing list of mods and bigger playsets.
